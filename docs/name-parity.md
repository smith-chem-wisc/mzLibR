# Name parity with pyMzLib and the wire

Generated by `scripts/name-parity.R`. Do not edit by hand; re-run it.

pyMzLib is the parent binding. Names flow pyMzLib -> mzLibRust -> mzLibR.
R has no per-module namespace and no methods, so `pride.list_files` becomes
`pride_list_files()` and `Digest.truncated` becomes `digest_truncated()`. That flattening
is the only renaming mzLibR is entitled to do.

## data.frame columns against the wire

The wire's field names are the snake_case of mzLib's own. A column marked *derived* is not
on the wire; every other column must match a wire field exactly.
