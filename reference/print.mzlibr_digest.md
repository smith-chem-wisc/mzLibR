# Print a digest

A compact summary of the digest and its fragment series.

## Usage

``` r
# S3 method for class 'mzlibr_digest'
print(x, ...)
```

## Arguments

- x:

  An
  [`peptidoform_fragments`](https://smith-chem-wisc.github.io/mzLibR/reference/peptidoform_fragments.md)
  result.

- ...:

  Ignored.

## Value

`x`, invisibly.
